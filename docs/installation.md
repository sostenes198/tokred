# Installation

Installing and configuring are **two separate steps**. No installation channel touches the Claude Code folder; the integration only happens when you run `tokred configure`.

```sh
brew install sostenes198/tap/tokred   # 1. install the CLI
tokred configure                      # 2. integrate with Claude Code
```

## Channels

| OS | Command | Published by |
|---|---|---|
| macOS / Linux | `brew install sostenes198/tap/tokred` | Formula in the `sostenes198/homebrew-tap` tap, generated by `dist` on each stable release |
| Windows | `winget install tokred` | Manifest submitted to `winget-pkgs` by CI on each release |
| Windows | `scoop bucket add sostenes198 https://github.com/sostenes198/scoop-bucket` then `scoop install sostenes198/tokred` | Manifest in the `sostenes198/scoop-bucket` bucket, updated by CI |
| Any | shell script (`curl … \| sh`) or PowerShell (`irm … \| iex`) | Generated by `dist` |
| Any | `cargo install tokred` | crates.io |

Releases are built by [`dist`](https://opensource.axo.dev/cargo-dist/) for macOS, Linux (musl) and Windows on x86_64 and aarch64, each archive with a `.sha256` checksum. Before the first release is published, build from source:

```sh
cargo install --path crates/tokred-cli
```

## Optional: the local proxy

The [proxy](proxy.md) is controlled by one switch, `[proxy] enabled` in `tokred.toml` (`tokred configure` turns it on for a new installation; `tokred proxy disable` turns it off). While it is on, `tokred initialize` (what the `claude` shell wrapper runs before every launch) starts the proxy when needed and keeps `env.ANTHROPIC_BASE_URL` in Claude Code's `settings.json` pointing at it; `tokred unconfigure` removes that URL again. Your own gateway in `ANTHROPIC_BASE_URL` is never overwritten.

```sh
tokred claude                     # start the proxy if needed and run Claude Code through it, for this run only
tokred proxy service install      # optional: start the proxy at login, as a user service
```

`tokred compression on` is the only command that edits Claude Code's user config (`~/.claude.json`, with a `.tokred.bak` backup), and only when you run it.

## Updating

`tokred update` detects how tokred was installed from the executable path and does the right thing:

| Method | Path contains | What `tokred update` does |
|---|---|---|
| Homebrew | `Cellar` or `linuxbrew` | Prints `brew upgrade tokred` |
| winget | `WinGet\Packages` or `WinGet\Links` | Prints `winget upgrade tokred` |
| scoop | `scoop\apps` or `scoop\shims` | Prints `scoop update tokred` |
| cargo | `.cargo/bin` | Prints `cargo install tokred --force` |
| Script | anything else | Self-updates (download, checksum, atomic swap) |

After the binary changes version, the first CLI command re-applies the configuration non-interactively. Hooks never do this; `tokred doctor` shows when a reconfiguration is pending.

## Version check

Once a day, from CLI commands only (never from a hook), tokred asks GitHub for the latest release with a 2 s timeout and prints a one-line notice on **stderr** if a newer version exists, so `--json` output is not affected. Disable it with `[update] mode = "off"` or `TOKRED_NO_UPDATE_CHECK=1`; `TOKRED_OFFLINE=1` turns off every network call (version check and price sync).

## Publishing a release (maintainers)

Push a tag `vX.Y.Z`. The generated `release.yml` builds the archives and installers and publishes the Homebrew formula; `publish-package-managers.yml` then updates the Scoop bucket, opens the winget pull request, adds the `tokred configure` caveat to the formula and publishes the crates to crates.io. These repository secrets must exist: `HOMEBREW_TAP_TOKEN`, `SCOOP_BUCKET_TOKEN`, `WINGET_TOKEN`, `CARGO_REGISTRY_TOKEN`. The winget package needs its first manifest submitted by hand once. Step by step: [release](release.md).

## Uninstalling

```sh
tokred proxy service uninstall   # only if you installed the proxy service
tokred compression off            # only if you turned compression on
tokred unconfigure --purge        # removes hooks, agents and the data folder
brew uninstall tokred             # or: winget uninstall tokred / scoop uninstall tokred / cargo uninstall tokred
```

`tokred unconfigure` removes only what tokred added to the Claude Code folder. The binary itself is removed by the package manager.

# Installation

Installing and configuring are **two separate steps**. No installation channel touches the Claude Code folder; the integration only happens when you run `tokred configure`.

```sh
brew install sostenes198/tap/tokred   # 1. install the CLI
tokred configure                      # 2. integrate with Claude Code
```

## Channels

| OS | Command | Published by |
|---|---|---|
| macOS / Linux | `brew install sostenes198/tap/tokred` | Formula in the `sostenes198/homebrew-tap` tap, generated by `dist` on each stable release |
| Windows | `winget install tokred` | Manifest submitted to `winget-pkgs` by CI on each release |
| Windows | `scoop bucket add sostenes198 https://github.com/sostenes198/scoop-bucket` then `scoop install sostenes198/tokred` | Manifest in the `sostenes198/scoop-bucket` bucket, updated by CI |
| Any | shell script (`curl … \| sh`) or PowerShell (`irm … \| iex`) | Generated by `dist` |
| Any | `cargo install tokred` | crates.io |

> **Status:** the release pipeline (`dist`, tap, bucket, winget) is part of phase F1. Until the first release, build from source:
>
> ```sh
> cargo install --path crates/tokred-cli
> ```

## Updating

`tokred update` (phase F1) detects how tokred was installed from the executable path and does the right thing:

| Method | Path contains | What `tokred update` does |
|---|---|---|
| Homebrew | `Cellar` or `linuxbrew` | Prints `brew upgrade tokred` |
| winget | `WinGet\Packages` or `WinGet\Links` | Prints `winget upgrade tokred` |
| scoop | `scoop\apps` or `scoop\shims` | Prints `scoop update tokred` |
| cargo | `.cargo/bin` | Prints `cargo install tokred --force` |
| Script | anything else | Self-updates (download, checksum, atomic swap) |

After the binary changes version, the first CLI command re-applies the configuration non-interactively. Hooks never do this; `tokred doctor` shows when a reconfiguration is pending.

## Version check

Once a day, from CLI commands only (never from a hook), tokred asks GitHub for the latest release with a 2 s timeout and prints a one-line notice on **stderr** if a newer version exists, so `--json` output is not affected. Disable it with `[update] mode = "off"` or `TOKRED_NO_UPDATE_CHECK=1`. (Phase F1.)

## Uninstalling

```sh
tokred unconfigure --purge   # removes hooks, agents and the data folder
brew uninstall tokred        # or: winget uninstall tokred / scoop uninstall tokred / cargo uninstall tokred
```

`tokred unconfigure` removes only what tokred added to the Claude Code folder. The binary itself is removed by the package manager.
